# 🏠 Медиакоми — Симулятор торгов

Интерактивный веб-сервис для оценки стоимости квартир в Республике Коми. Пользователь видит фото и описание квартиры и должен угадать её цену.

## 🎮 Механика

1. **Старт** — на главной странице пользователь нажимает «Запустить игру»
2. **10 раундов** — поочерёдно показываются 10 случайных объявлений
3. **Оценка** — бегунком пользователь указывает предполагаемую цену
4. **Результат** — показывается правильная цена, разница и баллы
5. **Итог** — подсчёт баллов, ранжирование, сумма переплаты/недоплаты

### Система баллов
| Точность | Баллы |
|----------|-------|
| ±5% | 100 |
| ±10% | 80 |
| ±15% | 65 |
| ±20% | 50 |
| ±30% | 35 |
| ±50% | 15 |
| >50% | 0 |

### Ранжирование
| Баллы | Категория |
|-------|-----------|
| 900-1000 | 🎯 Точный оценщик |
| 700-899 | 📈 Опытный инвестор |
| 500-699 | 🏠 Разумный покупатель |
| 300-499 | 💰 Щедрый инвестор |
| 0-299 | 🪙 Скряга |

## 🛠 Технологии

- **React** + **TypeScript** — UI
- **Tailwind CSS** — стилизация
- **Vite** — сборка
- Без тяжёлых библиотек, минимальный трафик

## 🚀 Запуск

```bash
# Установка зависимостей
npm install

# Разработка
npm run dev

# Сборка
npm run build

# Предпросмотр сборки
npm run preview
```

## 📱 Особенности

- Мобильная версия в приоритете
- Один экран = одна карточка
- Анимация бегунка при первом запуске
- Фотогалерея с автопрокруткой
- Прогресс-бар раундов
- Security headers (CSP, X-Frame-Options, nosniff, Referrer-Policy)
